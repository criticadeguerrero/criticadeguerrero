# Crítica de Guerrero

Rebuild project for Crítica de Guerrero, a Spanish-first news publication serving Guerrero, Mexico.

## Current foundation

- Static homepage foundation deployed through Netlify.
- `old_index.html` preserves the legacy captured homepage and must not be treated as the active site.
- Project planning lives in `docs/`.
- The next product milestone is a secure editorial workflow so a non-developer can publish stories and images.

## Working principles

- Spanish is the primary editorial language.
- English is an optional, reviewed companion edition; it is not an automatic replacement for Spanish reporting.
- Keep public delivery images optimized, while preserving original high-resolution assets separately and privately.
- Keep ownership, recovery, billing, and publishing access under publication-controlled accounts—not a single personal account.
- Never commit passwords, recovery codes, API keys, tokens, billing details, or private account settings.
